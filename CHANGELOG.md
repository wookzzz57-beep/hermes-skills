# Changelog

All notable changes to this project are documented here.

## 0.1.0 — 2026-09-18

### Added

- `durable-task` Agent Skill for explicit objective, scope, non-goals, constraints, acceptance criteria, and stop conditions.
- `checkpoint-resume` Agent Skill for interruption-safe handoff across sessions and providers.
- `evidence-gate` Agent Skill for evidence-first completion review.
- `hermes-durable` zero-runtime-dependency Python CLI.
- Atomic checkpoint/task writes and append-only JSONL evidence records.
- Task ID path-traversal protection.
- GitHub Actions validation and unit tests.
- English and Simplified Chinese documentation.
- Reproducible interruption/resume example.
